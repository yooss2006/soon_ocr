OCR 도우미 1.0

이 Mac에서 스캔 PDF를 검색 가능한 PDF로 변환합니다.
실행 환경과 모델은 앱 안에 들어 있습니다. 외부 서버에 문서를 보내지 않습니다.

시작하기
1. OCR 도우미.app을 엽니다.
2. PDF 선택을 누릅니다.
3. 필요하면 저장 위치를 바꿉니다. 원본과 다른 이름으로 저장합니다.
4. 샘플 변환을 누릅니다. 최대 5쪽을 먼저 처리합니다.
5. 샘플 PDF를 열어 확인하고, '샘플을 확인했습니다'를 선택합니다.
6. 전체 변환 시작을 누릅니다.
7. 끝나면 '완성 PDF 열기'와 '검토 보고서'를 확인합니다.

중단하고 이어서 처리하기
- 중단 버튼을 누르면 안전한 지점에서 멈춥니다.
- 앱을 다시 열고 최근 작업에서 해당 PDF를 선택합니다.
- 샘플 이어하기 또는 전체 변환 이어하기를 누릅니다.
- 완료한 페이지는 다시 처리하지 않습니다. 진행 중이던 페이지는 다시 처리할 수 있습니다.

일부 페이지가 실패한 경우
- 한 번 자동으로 다시 시도합니다.
- 그래도 실패하면 최종 PDF에 원본 페이지를 포함합니다.
- '미처리 쪽 다시 시도'로 실패한 페이지만 다시 처리할 수 있습니다.

처리 범위
- 원본 모양과 페이지 순서를 유지합니다.
- 이미 글자가 있는 페이지는 추가 OCR 없이 보존합니다.
- 표·수식 인식 결과는 검토 보고서에 표시합니다. PDF의 원문을 그 결과로 자동 교체하지 않습니다.
- 경고가 없어도 오인식이 있을 수 있습니다. 중요한 숫자와 수식은 원본과 대조하세요.
- 암호가 설정된 PDF는 암호를 해제한 사본을 사용하세요.

저장 위치
- 완성 PDF: 앱에서 선택한 위치
- 원본 사본, 처리 기록, 검토 보고서: ~/Library/Application Support/OCR Helper/jobs
- 이 기록을 지우면 이어서 처리할 수 없습니다.

실행 환경
- Apple Silicon Mac, macOS 26 이상
- 이 Mac에서 로컬 실행을 검증한 앱입니다.
