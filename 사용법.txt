OCR 도우미 1.0

이 Mac에서 스캔 PDF를 검색 가능한 PDF로 변환합니다.
실행 환경과 모델은 앱 안에 들어 있습니다. 외부 서버에 문서를 보내지 않습니다.

시작하기
1. OCR 도우미.app을 엽니다.
2. 'PDF 첨부…'를 누릅니다. 검색 가능한 PDF도 첨부할 수 있습니다.
3. 앱이 실제 텍스트를 확인합니다. 이미 OCR된 PDF는 AI용 정리 단계로 이동합니다.
4. OCR이 필요하면 '전체 OCR 바로 시작'을 누릅니다. 샘플 테스트는 선택 사항입니다.
5. 먼저 확인하려면 '샘플 테스트 시작'을 누릅니다. 최대 5쪽을 변환합니다.
6. 샘플을 테스트한 경우 '원본 PDF 열기'와 '샘플 PDF 열기'로 결과를 비교할 수 있습니다.
7. 필요하면 OCR PDF 저장 위치를 바꾸고 '전체 OCR 시작'을 누릅니다.
8. 완료 후 AI용 결과를 저장합니다. 원문은 요약하거나 수정하지 않습니다.
- 샘플이 미처리된 경우 다시 테스트하거나 전체 OCR을 진행할 수 있습니다.
- PDF 확인에 실패하면 오류를 확인하고 '다시 확인'을 누르세요.

중단하고 이어서 처리하기
- 중단 버튼을 누르면 안전한 지점에서 멈춥니다.
- 앱을 다시 열고 최근 작업에서 해당 PDF를 선택합니다.
- 샘플 이어하기 또는 전체 변환 이어하기를 누릅니다.
- 완료한 페이지는 다시 처리하지 않습니다. 진행 중이던 페이지는 다시 처리할 수 있습니다.

일부 페이지가 실패한 경우
- 한 번 자동으로 다시 시도합니다.
- 그래도 실패하면 최종 PDF에 원본 페이지를 포함합니다.
- '미처리 쪽 다시 시도'로 실패한 페이지만 다시 처리할 수 있습니다.

처리 범위
- 원본 모양과 페이지 순서를 유지합니다.
- 이미 글자가 있는 페이지는 추가 OCR 없이 보존합니다.
- 표·수식 인식 결과는 검토 보고서에 표시합니다. PDF의 원문을 그 결과로 자동 교체하지 않습니다.
- 경고가 없어도 오인식이 있을 수 있습니다. 중요한 숫자와 수식은 원본과 대조하세요.
- 암호가 설정된 PDF는 암호를 해제한 사본을 사용하세요.

저장 위치
- 완성 PDF: 앱에서 선택한 위치
- 원본 사본, 처리 기록, 검토 보고서: ~/Library/Application Support/OCR Helper/jobs
- 이 기록을 지우면 이어서 처리할 수 없습니다.

실행 환경
- Apple Silicon Mac, macOS 26 이상
- 이 Mac에서 로컬 실행을 검증한 앱입니다.

AI용 텍스트 저장
1. OCR을 마친 PDF를 선택하거나 최근 작업을 불러옵니다.
2. 기본 형식 '구조 + 원본 이미지'에서 'AI용 결과 저장…'을 누르면 새 폴더에 저장합니다.
   기존 방식이 필요하면 '텍스트만'을 선택하세요.
3. '50쪽씩 나눠 저장'을 선택하면 새 폴더에 분할 파일을 저장합니다.
4. 'AI용 결과 열기'로 파일 또는 폴더를 엽니다. 필요한 .md 파일을 AI에 전달하세요.
- 완료한 작업의 OCR 결과는 재사용합니다. 구조 정보가 없는 기존 OCR PDF는 원본 화면을 다시 분석합니다.
- 모든 쪽의 OCR이 완료돼야 저장할 수 있습니다. 미처리·실패·손상된 기록이 있으면 저장을 막습니다.
- 이미 OCR된 PDF는 선택 후 검사만 통과하면 바로 저장할 수 있습니다.
- 텍스트 없는 쪽에 그림이 있으면 로컬 인식기로 OCR 필요 여부를 확인합니다. 검사 중에는 잠시 기다리세요.
- 텍스트가 전혀 없는 PDF는 먼저 OCR 변환을 완료해야 합니다.
- PDF 쪽 번호를 유지합니다. 책에 인쇄된 쪽 번호와 다를 수 있습니다.
- 기본 형식은 텍스트 영역, 표의 셀·병합 범위, 수식 후보와 원본 이미지를 보존합니다.
- 그림의 연결 관계는 JPG에서 확인할 수 있습니다. 텍스트만 선택하면 이미지는 제외됩니다.
- 폴더의 안내 파일을 읽고 Markdown과 필요한 JPG를 ChatGPT에 직접 첨부하세요.
- Markdown의 이미지 링크만으로는 이미지가 ChatGPT에 전달되지 않습니다.
- 원본 대조.html에서 원본과 추출 결과를 함께 확인할 수 있습니다.
- 원본 구조 분석을 중단한 뒤 다시 저장하면 완료한 쪽의 분석을 재사용합니다.
- 내용을 요약하거나 오탈자를 자동 교정하지 않습니다. 텍스트가 없는 쪽은 표시합니다.
- 분할 저장은 50쪽 단위입니다. AI 서비스의 입력 한도를 보장하지 않습니다.
